Object detectorHigh-level API for object detection tasks. Supports YOLO, SSD, Faster R-CNN and other detection models.

// Create detector
auto detector = Detector("yolox-s", "cuda:0");
// Detect objects
auto results = detector.predict("image.jpg");
for (const auto& det : results.detections) {
std::cout << det.label << ": " << det.confidence
<< " @ " << det.bbox.x1 << "," << det.bbox.y1 << std::endl;
}
