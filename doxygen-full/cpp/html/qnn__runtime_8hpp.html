Detailed Description

Qualcomm QNN backend runtime.

Supports Qualcomm AI Engine Direct (QNN) for inference on:

  • HTP (Hexagon Tensor Processor) — NPU acceleration
  • GPU (Adreno GPU) — GPU acceleration
  • CPU — CPU fallback

Target hardware: Qualcomm IQ6/IQ8/IQ9 series, QCS9075, QCS8550, etc. Requires: Qualcomm AI Engine Direct SDK (QNN SDK 2.x)
