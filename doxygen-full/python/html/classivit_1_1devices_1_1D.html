Detailed Description

Device constants for quick access.

Example:
    >>> model = ivit.load("model.onnx", device=ivit.D.AUTO)
    >>> model = ivit.load("model.onnx", device=ivit.D.CPU)
    >>> model = ivit.load("model.onnx", device=ivit.D.CUDA)
