Detailed Description

Video stream reader.

Supports video files, cameras, and RTSP streams.

Examples:
    >>> stream = VideoStream("video.mp4")
    >>> for frame in stream:
    ...     results = model.predict(frame)
    >>> stream.release()

    >>> # Or with context manager
    >>> with VideoStream(0) as stream:  # Camera
    ...     for frame in stream:
    ...         process(frame)
