Detailed Description

OpenVINO runtime configuration.

Provides access to Intel-specific optimizations.

Examples:
    >>> model.configure_openvino(
    ...     performance_mode="LATENCY",
    ...     num_streams=4,
    ...     inference_precision="FP16",
    ... )
