Detailed Description

TensorRT runtime configuration.

Provides access to NVIDIA-specific optimizations.

Examples:
    >>> model.configure_tensorrt(
    ...     workspace_size=1 << 30,  # 1GB
    ...     dla_core=0,
    ...     enable_fp16=True,
    ... )
