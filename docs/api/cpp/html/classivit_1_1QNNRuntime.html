Detailed Description

Qualcomm QNN runtime implementation.

Loads serialized QNN context binaries and executes inference via Qualcomm AI Engine Direct.

Device strings recognised: "htp" | "iq6" | "iq8" | "iq9" | "hexagon" | "dsp" → HTP backend "qnn:gpu" → Adreno GPU backend "qnn:cpu" → QNN CPU backend
